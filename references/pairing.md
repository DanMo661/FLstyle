## 1. 换肤规则表（深浅同构，像素级仅换色板）

几何/字号/圆角/间距换主题完全不变；强调蓝的载体集合两主题一个不多一个不少。变化只有：

| Token | 浅色 | 深色 | 规则 |
|---|---|---|---|
| 画布 | #E6E4E7（L90） | #131315 | 两端极值 |
| 框架（标题栏/侧栏同色） | #E4E2E4（L89，比画布**暗**） | #1B1B1E（L11，比画布**亮**） | 凹陷↔浮起翻转 |
| 卡片 | #FCF8F9（L98） | #252628 | 唯一"浮起"层 |
| 次级表面（徽章=嵌套井=未选分段=装饰纹，同一 token 四处复用） | #EFEDEF（L93） | #323235 | 朝灰带走一档 |
| 侧栏选中药丸 | ~#DEDEDE | #353538 | 都朝"衬出选中"方向 |
| 交互井（OFF 开关轨/CN 徽章/播放圆） | #E4E2E4（=侧栏色） | #404042 | 深色独立成更亮一档 |
| 分隔线 | onSurface 14% 透明 | #424346（卡上 +0x1C） | 1 物理px 发丝线 |
| 主文字 | #181C23（对比 16:1） | #F5F6FF（14:1） | 反相 |
| 次文字/图标（**同一个 token**） | #414755（8.8:1） | #C1C6D7（8.9:1） | 反相，对比度几乎不变 |
| 三级灰（仅分组标题） | — | #9EA2B0（6:1） | |
| 强调蓝 | #007AFF（像素正点） | #2F83FF | **深色提亮提饱和，不是同值** |
| 成功绿对 | 底 #94F990 / 字 #005313 | 底 #005313 / 字 #94F990 | **前后景精确互换** |

深色全部灰是**冷调 slate**（B 通道比 R 高 2-5，如 #1B1B1E、#252628、#404042），不是中性灰；浅色近中性。深色下阴影仍然存在（卡片夹缝把画布压暗到 #0E0E10），侧栏交界深色是**亮缝**、浅色是**暗缝**。

## 2. 表面阶梯（嵌套方向铁律）

深色单调阶梯（每档 +8~14）：画布 #131315 → 框架 #1B1B1E → 卡 #252628 → 次级 #323235 → 选中药丸 #353538 → 交互井 #404042。
浅色从卡（最亮）向下：卡 #FCF8F9 → 次级表面 #EFEDEF → 画布 #E6E4E7 → 侧栏/交互井 #E4E2E4。
⚠️ 全部 hex 为像素级实测（两轮视觉代理在分段器/ thumb 色上互相矛盾，最终以像素采样裁决为准——视觉模型单轮描述不可信，争议色值必须取样核验）。
**统一律：子表面永远从宿主出发朝中性灰带走一档（浅色=变暗、深色=变亮），全应用无一处反向嵌套。** 语义区别不在方向，在档距：内容子块 +1 档，可交互井再 +1 档（深色 #252628→#323235→#404042）。

## 4. 颜色搭配清单（强调蓝 + 状态色 + 灰阶）

**强调蓝的全部合法载体（7 种，两主题一致，缺一不像）：**
1. 分段器选中药丸底（实心 + onPrimary 白字）
2. 开关 ON 轨道（thumb=onPrimary 白）
3. 方圆角图标容器底（50×50 r14 + 白 glyph）——**容器底色即状态指示：开启项才有蓝容器，关闭项是裸描边图标或卡色底**
4. 前景图标（下载箭头/选中勾/激活动作）
5. 选中导航左缘竖条（4×40）
6. 15% 透明底变体（`primary.opacity15` 底 + primary 字，用于计数 chip、过期 chip）
7. 圆形进度弧 / 图表第二序列（45% alpha 叠卡片色）

**明令禁止**（官方 .agents/surfaces.md）：primaryContainer 禁入卡片/行/导航指示器；选中项保持中性填充只加 primary 标记；值/正文文字永不染 primary；状态色只上文字/glyph/小 chip，不上整卡；outline 不可作文字色。

**灰阶 7 档各自配什么前景**（浅色）：L100 卡←黑字；L96 画布←黑字+灰说明；L94 子卡←灰图标+黑标题；L91 侧栏/装饰←黑字；L89 开关轨←深灰滑块；L87 选中药丸←黑字；分隔线不配字。

**opacity 固定档位**（源码唯一允许的透明度值）：0.8 / 0.6 / 0.5 / 0.38 / 0.3 / 0.15 / 0.12 / 0.1。

## 5. 组件配方

### hero 状态卡（657×207 逻辑，r≈18）
头部行：脉冲图标 24 —12— 「状态」17 w600 —15— 灰药丸「未运行」（h29-32 胶囊，深字）。
主体行：花形徽章 72×70 —15— 纵列（IP 大字 40 w700 tabular；+11；药丸行：灰药丸「移动网络」+12+绿药丸「质量 优」）。徽章与纵列**顶对齐**。
信息行两列（列距 83）：固定对⑤ 标签/值（运行时长/组织）。**列 2 与上方 IP 左缘对齐、列 1 与徽章左缘对齐——上下共用两条纵向栅格线**。
右侧：花形灰 blob（次级表面色 #EFEDEF/#323235）被卡圆角裁切，其上播放圆 **⌀117**（交互井底 + 次文字色三角，**完全由 token 组装所以换肤自动反相**），三角向右偏 4px 光学居中。

### 上传/下载双 KPI 卡（322×205）
头部：↑图标 24 —12— 「上传」17 w600 ……右端「峰值 xx」13 灰（距卡右 22）。
数字区：固定对④（40 tabular + 13 单位基线对齐）；下方 +10「累计 0 B」13 灰。
**卡高固定，内容顶置，底部留白 ~87 逻辑——是节奏不是失误，两卡一致。**
**不对称强调：上传箭头次文字灰、下载箭头蓝——同构位置不同色，颜色不对称承载方向语义，复刻别顺手对称化。**

### 分段器（⚠️ 像素裁决：整体连续轨道 + 段间细缝，两轮视觉代理曾对此各执一词）
卡内单行垂直居中：筛选图标 22 —14— 「出站模式」17 w600 —27— **连续圆角轨道 527×47（radius 全圆），三等分**；选中段**通高**刷蓝白字，未选段=轨道灰底黑字；**段间 3px 卡色细缝**（采样在两处段界都测到 ~5px 异色缝）；段内纯文字（无图标）；无描边、无滑动滑块。

### 开关行卡（63 逻辑高）
**⌀35 正圆图标容器**（像素探针裁决：圆不是圆角方）—22— 纵列（固定对③：17 黑 + 13 灰副标题）……开关 49×32。三者垂直居中。
开关：ON=蓝轨+白 thumb 右；OFF=浅 `#E4E2E4` 轨 + **thumb `#717786`**（深色：`#404042` 轨 + thumb `#8B90A0`）——**thumb 永远与轨道拉大对比**（浅色 thumb 比轨深、深色 thumb 比轨亮）；thumb 无阴影、轨道无描边。

### 列表行（分组列表/设置页，行节距 55）
描边图标 26 —26— 标题 17 …… 尾槽（右内边距 18-22）。
**分隔线 = 缩进线：起点=文字左缘、终点=尾槽左缘，绝不通栏**，≈1px，onSurface 14%。
选中=尾槽蓝对勾（⌀27 描边 3），未选=槽位空但保留。
三选一行的缩略图 62×42 r8 + 1.5px 描边，内容是主题本身的迷你截图。

### 主题预览大卡
白卡内水平居中放手机 mockup（240×470 r30 + 2px 描边），内部全是**缩小的真实组件**（迷你开关/迷你分段/迷你导航，强调元素用正牌蓝），不是抽象色块。

### 代理卡（数据密集页，源码 card.dart）
节点名 subheadline 15/20；类型缩写 footnote 13 + onSurface 80%；延迟 caption2 11 w600 + delayColor，"123 ms" 格式；卡 r20、水平内边距 12；名与详情间 8；卡内图标 20。
**选中态不变填充无边框**：右上角出现 22px 圆 badge（在用=实心 primary+白勾 16；pinned=tonal primary 14% 底+primary 图钉）。
组头：组名 callout 16 w600 +2+ 当前节点 caption1 12 w600 次色；组图标井=抬升面底 r24-10 + onSurfaceVariant 图标。
网格间距 8。顶部分组 tab：选中实心蓝胶囊白字 h16 内边距，未选只有文字。

### Chip 体系（源码 chip.dart）
CommonChip：底=**抬升面（中性，非主题色）**，字=onSurfaceVariant caption1 12 w600，r8，padding 8/3，删除图标 14。
TonalChip 三种合法配色：中性=抬升面+次文字；强调=primary 15% 底+primary 字；状态=container 色+onContainer 色（warning/error）。
ExpireChip：胶囊，色=过期?红:蓝，底=该色 15% 透明。

### 延迟颜色（源码 color.dart:333）
**单阈值 600ms**：<600 绿(success tone40/80)、≥600 橙(warning tone40/80)、<0 红(error)、null 继承色。没有 200/500 多档。超时文案「超时」。

## 6. 圆角 9 值刻度 + 图标尺寸档

**圆角全集**（源码 shape.dart，仅此 9 个）：0 / 4(snackbar/tooltip) / 8(chip/缩略图) / 16(常规卡/弹窗菜单) / 20(代理卡/卡内子块) / 24(组头井/底sheet内) / 28(底sheet/大卡) / 34(对话框/移动大卡) / 1000 胶囊(一切按钮)。仪表盘自用一套更大刻度（卡实测 r≈18-19），但同样取值 disciplined。
**图标尺寸档**：24 默认（描边 1.8）/ 20 卡内 / 18 chevron·复制 / 16 badge 勾 / 14 chip 关闭 / 19 定位 / 26 区块头。
**图标风格**：统一 outline 描边 1.5-1.7 逻辑、圆角连接（Material Symbols Rounded / Lucide 风）；颜色=**次文字 token 本尊，不单设图标灰**；只有激活动作/状态上蓝；无一处填充式彩色图标（唯一例外=蓝底白 glyph 状态容器）。
**chevron**：18×18、描边 ~1.7、圆头、禁用灰（#9AA0A6 级），永远独占行尾。
