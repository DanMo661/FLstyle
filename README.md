# FLstyle

前端审美体系 skill——把成熟软件的设计系统（真机逐像素实测版）做成 AI 编码助手可直接执行的工作规范：设计宪法、数字标尺版面骨架、可抄骨架代码、拉伸重排规则、动效参数（录屏抽帧实测）、以及**基准样本截图比对验收闭环**。

v1 内置「工具类」风格包；后续其它审美（拟物、HIG、Material、其它标杆应用…）以 `shots-<name>/` 风格包形式扩展，SKILL.md 通用层（宪法/比对闭环/双平台映射）共享。

## 什么时候用

- "做一个精致的、像成熟商业软件那样的工具界面"
- 把串口助手、传感器上位机这类工程工具从"能用"拉到"正经软件"
- Web（HTML/CSS）或桌面（PySide6/Qt）双平台

## 安装

把本仓库放进你的 skills 目录（如 `~/.zcode/skills/` 或 `.claude/skills/`）：

```bash
git clone https://github.com/DanMo661/FLstyle.git ~/.zcode/skills/FLstyle
```

`shots/` 是基准样本库，必须随 SKILL.md 一起保留——本 skill 的核心方法就是"拿成品截图与样本逐区块比对，差异清单清空才算验收，打分无效"。

## 目录

- `SKILL.md` — 规范本体：A 流程层（铁律 → 看图 → 抄骨架 → 比对验收闭环 → 录屏抽帧 → 交付）+ B 规格层（v1 工具类风格包：表面体系 / tokens / 版面标尺 / 重排断点 / 形状语言 / 动效）
- `references/` — `skeleton.html` 骨架代码（含花形路径生成器）、`motion-notes.md` 动效完整参数与观测法、`pitfalls.md` 高发坑清单
- `shots/` — v1 风格包基准样本：浅/深仪表盘、空状态、列表页、子页、五档宽度重排序列、移动端深色（1400×1466@150%DPI，逻辑 px=物理÷1.5）

## 核心理念

> 审美传递的失败不在缺描述，而在链路无视觉：文字转述 → 盲写生成 → 打分验收，每一环都在丢信息。
> 治法是给每一环装上眼睛：动手前读样本，验收时逐区块比对样本，看不到的动效就录屏抽帧自己看。

所有色值、尺寸、断点、动效时长均为真机截图/录屏实测，非臆测。
